每篇只设置下列七个正文部分，保持详细的技术解读与原文配图。章节内部按论文实际内容展开，原文未公开的内容明确标注“原文未披露”。

|---|---|---|

| 5. 数据构建与处理 | 各阶段数据来源、类型、规模与单位、合成、清洗、筛选、混合比例和质量控制 | 原文数据流程图、分布图或统计表 |
| 6. 训练流程与目标 | 实际训练阶段、各阶段目的与数据、冻结及更新模块、损失函数、公开超参数、算力与成本 | 原文训练流程图，配简洁的训练阶段整理表 |
| 7. 实验设置与主要结果 | 基准与指标、对比模型、评测条件、主要结果及优势和权衡；按需解释支撑核心创新的关键消融 | 核心结果图 / 表；有必要的消融图表紧邻结果分析 |

## 图文写法

原图紧邻对应内容，统一写作顺序为：**原图展示 → 原编号与出处 → 如何读图 → 技术含义**。

- 使用论文正文、附录或官方补充材料的实际图表，记录确切版本、Figure / Table 编号、PDF 文件页码和来源链接。
- 每篇按原文情况选择架构、机制、数据、训练和实验中有信息量的图；通常 3–6 张，复杂报告可增加，不设硬性图数。
- 保留模块名、箭头、坐标、图例、单位与子图标签；局部展示标明对应原图与子图。
- 解读图中可见的结构、趋势及其作用。作者结论、解读者分析与补充推导在文字中区分。
- 原文无某类图或数据时如实说明。转写的结果表标明原表编号；不同评测条件的数字分开说明。
- 引用就近放在数字、公式、图表与相关论断旁边；原图清单、来源元数据和复核记录保存在单篇资产文件中。

## 介绍范围与仓库组织

沿用当前保留的 272 条资料：199 条模型文献候选、57 条补充材料、16 条范围待审。主模板用于模型文献；其余按实际类型在同一七部分框架内适配，发布博客仍标为发布资料，未披露的架构与训练信息如实说明。

保持“模型家族 → 单篇论文”的组织方式：

```text
papers/<family>/
  README.md                     # 家族与逐篇介绍索引
  <paper-id>/
    README.md                   # 七部分图文正文
    figures/                    # 原文图表
    metadata.json               # 文献信息与来源版本
    figures-manifest.json       # 原图编号、页码及本地路径
    review.json                 # 数字、公式、图表与链接复核
```

正文的信息量以原文为准。普通模型论文仍可按约 5,000–8,000 中文字符规划，信息充分的长报告可展开；章节数量与长度不作为填充目标。
